# Envinage AI - Complete Application Replica

A comprehensive replica of the Envinage AI platform as specified in the Product Requirements Document. This application demonstrates a unified workspace for AI-powered content creation, project management, and intelligent live previews.

## 🎯 Overview

Envinage AI is designed to revolutionize how users interact with and manage content generated by large language models (LLMs). It combines conversational AI power with robust project management and intelligent live preview capabilities, addressing critical pain points in current AI-assisted workflows.

### **Frontend Architecture**
- **React 18**: Modern hooks-based component architecture

- **Tailwind CSS**: Utility-first styling with custom gradient themes

### **State Management**
- **React Hooks**: useState, useEffect, useRef for local state
- **Complex State**: Projects, chats, messages, artifacts management
- **UI State**: Sidebar visibility, active views, preview content
- **Persistent State**: Expanded folders, user preferences

```
EnvinageAI (Main Component)

```

## 🔧 Getting Started

### **Prerequisites**
- Node.js 18+
- npm or yarn
- Modern web browser

### **Installation**
1. **Navigate to project**: Already integrated in existing Next.js app
2. **Install dependencies**: `npm install` (already done)
3. **Run development server**: `npm run dev`
4. **Access application**: Visit `http://localhost:3000/envinage`

### **Usage**
1. **Start chatting**: Type a message in the input area
2. **Try different requests**: Ask for code, images, or general help
3. **Explore projects**: Click Projects tab to see file management
4. **Preview content**: Click files or artifacts to see live previews
5. **Test features**: Try model switching, response modes, thinking mode
