# Envinage AI - Complete Application Demo

A comprehensive replica of the Envinage AI platform with unified workspace for AI-powered content creation, project management, and intelligent live previews.

## 🌐 Live Demo

You can access the Envinage AI application in two ways:

### Option 1: Standalone HTML Demo (Recommended)
Open the `envinage-ai-demo.html` file directly in your browser - no server required!

### Option 2: Next.js Application
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Visit: `http://localhost:3000/envinage`

### 🤖 **Intelligent AI Routing**
